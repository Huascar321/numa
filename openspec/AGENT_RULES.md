# OpenSpec agent rules

Read the relevant ordered `changes/001` through `changes/017` artifacts before work, and implement one ordered change at a time. Validate stated invariants and mark a task checkbox only after it is complete and verified.

- MUST never use floats, `cleared`, destructive merges, provenance loss, arbitrary SQL MCP, or mandatory AI.
- MUST NOT introduce microservices, Redis, or Kafka without an ADR.
- MUST stop and request clarification on financial ambiguity rather than inventing a value, mapping, or reconciliation.
- MUST keep secrets server-side and preserve human correction history.
- MUST NOT implement FUTURE or OPTIONAL behavior unless an accepted change explicitly activates it.
- MUST NOT alter prior change artifacts except through an accepted, scoped change.
