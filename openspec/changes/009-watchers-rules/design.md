# Design

Process Email → Watcher → Parser → deterministic Rules → optional AI →
Normalize → Deduplicate → Transaction. Typed contracts, stable rule ordering,
match evidence, replay, and quarantined failures preserve safe raw references.
Provider parsers recursively decode MIME and transfer encodings, retain raw
reported values and notification metadata, and produce Pending/reviewable bank
notice candidates when event facts are absent. Exact QR glosa rules may classify
subtypes without synthesizing missing glosa.
