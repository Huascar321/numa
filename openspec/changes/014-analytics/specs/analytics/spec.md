# Analytics delta

## ADDED Requirements

### Requirement: Scoped finance analytics
Analytics MUST provide plan/period-scoped income, expense, net, balances, comparisons, categories, merchants, tags, trends, heatmaps, and goal status.

#### Scenario: Transfer and unconverted data
- **WHEN** a report includes a transfer or unconverted currency
- **THEN** transfer is excluded and unconverted state is explicit.
